# 会计中级 · 经济法 题库练习

> 单文件、可离线、可云端同步的中级经济法刷题工具，覆盖《中级经济法》第 1–7 章 640 题。

## 使用

双击 `index.html`（或访问本 Pages 站点）→ 选择账号（jiaqu / syy）→ 章节练习 / 随机出题 / 错题本 / 收藏夹。

## 云端进度同步

- 基于 GitHub Gist（本仓库独立 Gist，与财管隔离），文件 `progress_<user>.json`。
- 设置：页内 ⚙ → 粘贴具有 gist 权限的 PAT。PAT 仅存浏览器 localStorage，绝不写入源码。

## 部署纪律

仅在明确指示「部署」时推送。新增/删题会改变题号位置索引，可能影响旧进度映射。
